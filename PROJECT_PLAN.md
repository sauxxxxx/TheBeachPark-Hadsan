# The Beach Park Website — Delivery Plan

## Phase 1 — Foundation and homepage shell

- Vue 3 and Vite application foundation
- Editorial-coastal design tokens and responsive layout system
- Accessible global header, footer, homepage structure, and booking calls to action
- `/booking/` route reserved for property ID `507010`
- Mockup images and unverified pricing excluded from production content

## Phase 2 — Stays and content model

- Confirm the active room catalogue and approved room photography
- Build room listing, filters, room details, galleries, amenities, and occupancy presentation
- Map public room content to stable Exely room identifiers
- Preserve or permanently redirect existing room URLs

## Phase 3 — Dining, adventures, and experiences

- Build Beans & Paddles, Sharky's, Waterdog, day-visit, and experiences sections
- Replace placeholders only after hours, menus, pricing, booking methods, and assets are approved
- Separate informational experiences from products actually bookable through Exely

## Phase 4 — Offers, explore, and content operations

- Offers and packages, gallery, about, contact, directions, and policy pages
- SEO metadata, structured data, analytics baseline, accessibility, and performance work
- Establish an editable content source appropriate for the operating team

## Phase 5 — Exely integration

- Install the official Exely custom-site integration package
- Keep property/provider ID `507010` and `/booking/`
- Integrate availability, rates, reservations, guest account/loyalty, and Reputation Manager as approved
- Configure production and staging origins plus conversion-event tracking
- Run complete booking, cancellation, payment, email, mobile, and failure-path tests

## Phase 6 — Migration and launch

- Final content and business sign-off by Hadsan
- URL redirect map, DNS/SSL/analytics verification, backups, and rollback rehearsal
- Controlled production cutover followed by booking and analytics monitoring
